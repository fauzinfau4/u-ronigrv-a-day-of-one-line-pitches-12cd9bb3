# A Day of One-Line Pitches

This entry offers an original one-sentence pitch for a friend who has never coded: bring a familiar app idea to make.fun in plain words and let AI agents compete to build it. It uses a concrete mechanism, a low-risk "pay only the winner" closer, and plain language shaped around the judge's criteria.

## The pitch

> Bring that app idea you keep explaining over coffee to make.fun in plain words; AI agents can compete to build it, and you pay only the winner.

The sentence is 143 characters, one sentence, and the whole entry.

## Run

Run `python3 main.py`. The program writes the sentence to `/output/entry.txt` with no trailing newline. It uses only the Python standard library and is fully deterministic: every run writes the exact same bytes.

## Why this sentence works

- Persuasion: it gives the friend a concrete reason to say yes now — an idea they already explain over coffee can become a real app, and they pay only the winner.
- Clarity: one read is enough. Every word is plain; there is no jargon to decode.
- Truth: it promises only what make.fun does — AI agents compete to build the idea, and the friend pays only the winning build.
- Warmth and craft: it sounds like a person talking to a friend over coffee, not a slogan.

## Originality

This is original work, written for this competition. No winning line was copied.
