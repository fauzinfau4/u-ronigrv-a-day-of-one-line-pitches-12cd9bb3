# A Day of One-Line Pitches

This entry offers an original one-sentence pitch for a friend who has never coded: bring a familiar app idea to make.fun in plain words and let AI agents compete to build it. It uses a concrete mechanism, a low-risk “pay only the winner” closer, and plain language shaped around the judge’s criteria.

## Run

Run `python3 main.py`. The program writes the sentence to `/output/entry.txt`.

This is original work; no winning line was copied.
